
O KernelLab é um projeto desenvolvido em Python com o objetivo de simular o funcionamento de alguns recursos de um sistema operacional. O simulador possui quatro algoritmos de escalonamento de CPU: FCFS, SJF, Round Robin e Prioridade. Cada algoritmo organiza a execução dos processos de uma maneira diferente, permitindo comparar os tempos de espera, retorno e resposta, além de visualizar a execução por meio de diagramas de Gantt. O projeto também implementa os algoritmos FIFO, LRU e Optimal para o gerenciamento de memória, analisando as faltas e os acertos de página. Além disso, apresenta uma simulação de dispositivos de entrada e saída, com filas de solicitações, permissões de acesso e exclusão mútua para evitar acessos simultâneos à região crítica.
